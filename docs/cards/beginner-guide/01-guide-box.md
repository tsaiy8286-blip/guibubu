# 01-新手說明框

**做完能看到什麼**：打開首頁，網站標題的金線下方、「一 起卦資訊」上方多一個深藍金框「第一次來？三步驟就能解卦」，裡面三步驟教新手準備三枚硬幣、擲六次、複製提示詞貼給自己的 AI。這台裝置第一次來時自動展開；之後再打開網站就收起來，點標題可以再展開。

**依賴**：無——可直接開工

**狀態**：已驗收

（狀態只有三種：待做 → 已完成 → 已驗收）

- [x] 第一次打開首頁（或用無痕視窗打開）：說明框自動展開，三步驟文字和規格一字不差
- [x] 點標題可以收起、再點展開；重新整理後預設收起
- [x] 框的樣子和其他區塊同款（深藍底、金框、角飾），沒有步驟編號
- [x] 下方起卦、擲卦、結果區、六十四卦都照常運作；卦典頁沒有這個框
- [x] 手機寬度：文字好讀、不需左右捲動，標題好點

**AI 實際操作驗過**（2026-10-10，Chrome 開本機臨時伺服器 127.0.0.1）：
- 第一次打開（全新網址、瀏覽器沒有記錄）→ 說明框自動展開；三步驟的標題＋內文逐字和 SPEC 比對，完全相同
- 點標題 → 收起；再點 → 展開；重新整理 → 預設收起
- 模擬瀏覽器擋下儲存 → 說明框照樣展開，沒有錯誤
- 結構：框用和其他區塊同一套樣式（深藍底、金框、左上右下角飾），標題沒有步驟編號圓圈；位置在金線下方、「一 起卦資訊」上方
- 填起卦資訊、擲六次 → 結果區出現「澤水困 → 水澤節」；六十四卦 64 格都在；卦典頁 gua.html 沒有這個框；強制重新整理後主控台沒有錯誤（一開始有「hexagramByNumber 未定義」，是瀏覽器留舊版 yao.js 的暫存，強制重新整理後消失，不是這次改動造成）
- 手機寬度 375px（用內嵌框量）：頁面寬 360、沒有左右捲動；標題一行放得下、點按區高 42px；截圖文字無被切掉
- `node test.js` 全部通過

**使用者人工驗收**：2026-10-10 使用者回報全部通過（外觀、文字、展開收起都看過）；手機實機項目照慣例延後到下次推上網站後
