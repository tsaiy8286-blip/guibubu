# 01-新手說明框

**做完能看到什麼**：打開首頁，網站標題的金線下方、「一 起卦資訊」上方多一個深藍金框「第一次來？三步驟就能解卦」，裡面三步驟教新手準備三枚硬幣、擲六次、複製提示詞貼給自己的 AI。這台裝置第一次來時自動展開；之後再打開網站就收起來，點標題可以再展開。

**依賴**：無——可直接開工

**狀態**：待做

（狀態只有三種：待做 → 已完成 → 已驗收）

## 驗收條件

- [ ] 第一次打開首頁（或用無痕視窗打開）：說明框自動展開，三步驟文字和規格一字不差
- [ ] 點標題可以收起、再點展開；重新整理後預設收起
- [ ] 框的樣子和其他區塊同款（深藍底、金框、角飾），沒有步驟編號
- [ ] 下方起卦、擲卦、結果區、六十四卦都照常運作；卦典頁沒有這個框
- [ ] 手機寬度：文字好讀、不需左右捲動，標題好點
