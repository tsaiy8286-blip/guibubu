# 04-自選卦做紀念圖

**做完能看到什麼**：首頁「六十四卦」區塊上方多一顆「✦ 自選卦做紀念圖」。按下後點卦名變成選卦：第一個是本卦、第二個是變卦，下方出現牌卡預覽、「我的啟發」和「⬇ 下載紀念圖」。紀念圖和結果區的一樣，只是上方寫「觀　象」、日期是下載當天。

**依賴**：02-首頁六十四卦區與卦名連結

**狀態**：待做

（狀態只有三種：待做 → 已完成 → 已驗收）

## 驗收條件

- [ ] 按「✦ 自選卦做紀念圖」→按鈕變「取消選卦」；點賁再點明夷：賁格子標「本」、明夷格子標「變」，預覽是賁＋箭頭＋鏡向的明夷
- [ ] 再點賁取消：明夷遞補為本卦，預覽只剩一張明夷
- [ ] 已選兩卦時點第三個卦：不會選上（最多兩個）
- [ ] 寫一段啟發，下載：圖上「觀　象」「賁　之　明夷」、兩張牌卡、啟發方框、今天日期；檔名「龜卜卜_賁之明夷_今天日期.jpg」
- [ ] 只選一卦下載：一張牌卡，檔名「龜卜卜_賁_今天日期.jpg」
- [ ] 按「取消選卦」：選取、預覽、啟發都清掉，點卦名又會換頁
- [ ] 上方正在起的卦（含結果區的我的啟發）完全不受影響；重新整理後選卦內容不保留
- [ ] 手機寬度：預覽和按鈕好按、不需左右捲動
