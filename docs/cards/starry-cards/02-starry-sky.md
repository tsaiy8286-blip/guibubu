# 02-流金星空背景

**做完能看到什麼**：打開網站，背景是會動的流金星空：斜向銀河柔光、藍白與金色星星輕輕閃爍、整片星空極慢地繞右上方旋轉、左上北斗七星金線慢慢描出再淡去、金色微塵緩緩往上飄、偶爾一道金色流星劃過。內容區塊蓋在星空上，捲動頁面時星空不跟著捲。

**依賴**：01-星夜外觀

**狀態**：已驗收

（狀態只有三種：待做 → 已完成 → 已驗收）

## 驗收條件

- [x] 打開網站：背景星空在動（星星閃爍、北斗七星金線描出又淡去、金色微塵上飄）
- [x] 等一兩分鐘內會看到至少一道金色流星
- [x] 捲動頁面：星空固定在背景，內容正常捲動、字看得清楚
- [x] 電腦或手機開啟「減少動態效果」後重新整理：星空靜止不動，但星星、銀河、北斗七星仍在
- [x] 手機上滑動、點按不卡頓
- [x] 手機尺寸下看起來正常

## 實作備註

- 動畫參數照 `素材/風格試看/a-starry.html`（約 40 分鐘一圈、北斗約 16 秒一輪）
- 切到別的分頁時暫停動畫以省電
- 程式在 `js/sky.js`；流星改成「每 15～40 秒一道、打開後 6～20 秒出現第一道」，速度依實際經過時間計算（不同螢幕更新率速度一致）
- 為了手機順暢，區塊拿掉毛玻璃（背景模糊）效果，改成稍微不透明一點（84%），外觀幾乎一樣
- 北斗七星位置：寬螢幕在左側空白、手機在畫面下方（避開頁首）
