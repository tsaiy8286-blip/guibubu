# 05-下載紀念圖

**做完能看到什麼**：「我的啟發」下方有一顆「⬇ 下載紀念圖」。按下顯示「製作中…」，接著下載一張 JPG：深藍星空底＋金色雙框，上方「占得」與金色大字「蹇　之　恆」，中間本卦牌卡＋箭頭＋鏡向的變卦牌卡，下方「本卦　水山蹇」「變卦　雷風恆」；有寫我的啟發時多一個金框方塊顯示「我 的 啟 發」與內容；右下角起卦日期＋「龜卜卜線上求卦」＋朱紅易印。不放問事內容。沒有動爻時只有一張牌卡、標題只寫本卦名。檔名如「龜卜卜_蹇之恆_20261009.jpg」。
