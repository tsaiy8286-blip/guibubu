# 02-起卦資訊與摘要列

**做完能看到什麼**：打開網頁，看到「起卦資訊」區：時間欄（預設空白，旁邊有「填入現在時間」按鈕）、問事類別下拉選單（工作、財運、經商、感情、家庭、健康、學業、官司、交友、尋人(物)、其他）、問事內容輸入框，以及「開始擲卦」按鈕。三欄都填好按鈕才會亮。按下後起卦資訊縮成一行摘要列（時間、類別、問事），旁邊有「修改」按鈕，點了展開回來可以改，改完再收回。摘要列下方先放占位文字「擲卦區施工中」。

**依賴**：01-頁面地基

**狀態**：已驗收

（狀態只有三種：待做 → 已完成 → 已驗收）

## 驗收條件

- [x] 時間欄一開始是空白；按「填入現在時間」會填入現在的日期與時分，而且可以再改
- [x] 手機上點時間欄，跳出手機內建的日期時間選擇器
- [x] 類別下拉選單有 11 個選項，順序正確，預設是「請選擇」
- [x] 三欄任一沒填，「開始擲卦」是灰色按不下去；三欄都填好才能按
- [x] 按下後縮成摘要列，顯示剛才填的時間、類別、問事
- [x] 點「修改」可以展開回來修改，改完摘要列跟著更新
- [x] 手機尺寸下看起來正常，按鈕好點
