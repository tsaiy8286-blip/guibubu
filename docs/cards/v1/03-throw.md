# 03-擲卦區

**做完能看到什麼**：按下「開始擲卦」後，摘要列下方出現擲卦區：標題「第 1 擲（初爻）」，四個按鈕 `0背`、`1背`、`2背`、`3背`，每個按鈕下方畫三枚小錢幣（背＝實心圓、字＝空心圓中間寫「寶」），按鈕上不寫答案。每點一次，卦象由下往上長出一爻（陽爻一長條、陰爻兩短條，動爻朱紅並標 ○ 或 ✕），記錄顯示「第 N 擲：X背Y字 ＝ 少陰，靜爻」。「退回上一步」可一路退回第一擲。六擲完成後擲卦按鈕收起，下方先放占位文字「結果區施工中」。

**依賴**：02-起卦資訊與摘要列

**狀態**：待做

（狀態只有三種：待做 → 已完成 → 已驗收）

## 驗收條件

- [ ] 四個按鈕的錢幣圖示正確：0背＝三個寫寶的空心圓、3背＝三個實心圓，1背、2背依此類推
- [ ] 按鈕上沒有寫老陰、少陽等答案
- [ ] 標題隨擲數更新：第 1 擲（初爻）…第 6 擲（上爻）
- [ ] 第一擲畫在最下面，之後一爻一爻往上長
- [ ] 每擲的解答正確：0背3字＝老陰動爻 ✕、1背2字＝少陽靜爻、2背1字＝少陰靜爻、3背0字＝老陽動爻 ○
- [ ] 動爻是朱紅色並標 ○ 或 ✕，靜爻是墨黑色
- [ ] 「退回上一步」收回最後一爻，可一路退回到第一擲
- [ ] 六擲後擲卦按鈕收起；此時退回一步，按鈕回來、可重擲第六擲
- [ ] 擲到一半按「修改」改問事，已擲的爻都還在
- [ ] 手機尺寸下看起來正常，四個按鈕好點
