# 03-擲卦區

**做完能看到什麼**：按下「開始擲卦」後，摘要列下方出現擲卦區：標題「第 1 擲（初爻）」，四個按鈕 `3正面`、`2正面`、`1正面`、`3背面`，每個按鈕下方畫三枚小錢幣（先畫字＝空心圓中間寫「字」，再畫背＝實心圓），按鈕上不寫答案。每點一次，卦象由下往上長出一爻（陽爻一長條、陰爻兩短條，動爻朱紅並標 ○ 或 ✕），記錄顯示「第 N 擲：X背Y字 ＝ 少陰，靜爻」。「退回上一步」可一路退回第一擲。六擲完成後擲卦按鈕收起，下方先放占位文字「結果區施工中」。

**依賴**：02-起卦資訊與摘要列

**狀態**：已驗收

（狀態只有三種：待做 → 已完成 → 已驗收）
