# 06-中途中斷接續

**做完能看到什麼**：填好起卦資訊、擲到一半時重新整理網頁（或關掉分頁再打開），剛才的時間、類別、問事與已擲的爻都還在，接著擲就好。六擲完成後重新整理，結果也還在。按「再起一卦」清除後，重新整理就是全新的空白頁。

**依賴**：05-複製到 Obsidian

**狀態**：待做

（狀態只有三種：待做 → 已完成 → 已驗收）

## 驗收條件

- [ ] 只填了起卦資訊、還沒按開始擲卦就重新整理 → 填的內容還在
- [ ] 擲到第三爻重新整理 → 摘要列與三爻都在，可接著擲第四擲
- [ ] 六擲完成後重新整理 → 結果區、複製區都在
- [ ] 按「再起一卦」清除後重新整理 → 空白頁
- [ ] 手機上擲到一半，切到別的 App 一陣子再回來 → 內容還在
- [ ] 電腦上擲到一半的卦，手機上看不到（各自獨立，符合預期）
