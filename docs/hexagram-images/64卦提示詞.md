## 怎麼用

1. 在 ChatGPT 開一個對話，先上傳**定裝照**（銅龜照片不用附，以免畫得太像實物）
2. 複製下面某一卦的整段方框內容，貼上送出
3. 畫好後檢查（AI 寫行書很常寫錯字）：
   - [ ] 上方題字每個字都對（尤其是卦名）
   - [ ] 畫面裡沒有多畫卦畫（卦畫由程式另外加上）
   - [ ] 下方「給妳的話」沒有多字、漏字
   - [ ] 沒有畫印章（易印由程式另外加上）
   - [ ] 臉、髮冠和定裝照是同一個；銅龜是簡化的圖案造型，只有龜殼（沒有頭腳）
4. 有錯就回覆 ChatGPT：「其他不變，只把○○改成△△」
5. 存檔名建議：`hexagram-39.png`（卦序兩位數），之後放上網站比較好整理

> 一次只畫一卦。同一個對話畫太多張，人物會慢慢走樣；大約每 5～8 張就開新對話，重新上傳定裝照。
